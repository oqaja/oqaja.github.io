Affiliate Automation

An internal tool by Oky Nurdianto for managing his own YouTube channels.

What it does

Affiliate Automation is a private, single-owner tool that helps manage the owner's own YouTube channels. It runs on scheduled GitHub Actions jobs and connects to YouTube through the YouTube Data API and YouTube Analytics API, after the owner grants access with Google OAuth. It:

  • uploads and schedules YouTube Shorts prepared by the owner;
  • reads video statistics and analytics (views, likes, comments, watch time) for the owner's own channels, and writes them to the owner's own Google Sheet;
  • posts a pinned first comment on the owner's own uploads.

Who can use it

Only the owner. The tool is not offered to the public and has no sign-up. It does not access any YouTube account other than the owner's own channels.
