Privacy Policy

Affiliate Automation · Last updated: 12 October 2026

Overview

Affiliate Automation is a private tool operated by a single individual, Oky Nurdianto ("the owner"), to manage the owner's own YouTube channels. It is not a public service and is used by the owner only. This policy explains what data the tool accesses and how it is handled.

Data accessed

When the owner authorizes the tool with Google OAuth, it can access, for the owner's own YouTube channels only:

  • video metadata and statistics (YouTube Data API);
  • channel and video analytics such as views, likes, comments, watch time and subscribers gained (YouTube Analytics API);
  • the ability to upload videos, update video details and post comments on the owner's own channels.

The tool does not collect personal data about any other person.

How data is used

Data is used only to provide the features described above: uploading and scheduling the owner's videos, and writing analytics about the owner's own channels to the owner's own Google Sheet. Data is not used for advertising, profiling or any other purpose.

Storage and security

OAuth refresh tokens are stored as encrypted secrets in the owner's private GitHub repository and are used only by the owner's scheduled jobs. Analytics data is stored only in the owner's own Google Sheet. No data is stored on any other server operated by the tool.

Sharing

The tool does not sell, rent or share data with any third party. The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The tool uses YouTube API Services. By using it, the owner is bound by the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

Revoking access and deletion

The owner can revoke the tool's access at any time at myaccount.google.com/permissions. Revoking access immediately stops the tool from reading or changing anything on the YouTube account. Stored tokens and sheet data can be deleted by the owner at any time.
